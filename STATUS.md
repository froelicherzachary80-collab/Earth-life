### V0.3 honest gaps
- **No .exe file is included in this zip.** It has to be produced on Windows (script) or by GitHub Actions; nothing here could run Windows tooling.
- Live feeds were tested only against recorded responses in the documented formats. Live requests couldn't be made from the build machine. If a provider changes its format, `/earthlife events status` shows the error.
- MLB Stats API terms allow personal, non-commercial use. Ticketmaster requires your own free key and their attribution.
- The Red Wings season is over (it's late October). Baseball events will show up next spring; holidays (Halloween now) work today.
- Event decorations are placed once around where players are when the event starts.
- Event tickets aren't required at the gate; they give a fan bonus.

## Honest gaps

- **Fabric mod never compiled** (both V0.1 and V0.2 code). Version-sensitive spots are flagged `UNVERIFIED` in comments: `McCompat`, access widener, entity save/hurt signatures, `getLastClientInput`, `NpcRenderer` generics, `DynamicTexture`, `GameRules`.
- Cabin walking has ~1 tick + ping of input lag, because the server moves you. Smooth client-side prediction is V0.3 work.
- Aircraft turn instantly at taxi corners (no turning radius on the ground yet).
- Pilot = checklist on an autopilot flight. No hand-flying yet.
- Bus driver job rides as operator; the bus drives itself. Delivery/janitor/clerk/construction/check-in/gate tasks are hands-on.
- Boats/ferries only work at sea level (Lake Ontario, Sodus Bay); there's no ferry route by default.
- Owned vehicles aren't saved as entities; they're re-summoned from the purchase record (ledger).
- NPC long-distance travel is simplified: they walk toward their destination in 40-block hops; despawn/respawn hides long commutes.
- Fallback airport runway coordinates and town centres are approximate until you run the import tools.
- `/earthlife sell` works anywhere (not restricted to a market yet).
